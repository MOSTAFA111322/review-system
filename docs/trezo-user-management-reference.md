# مرجع تصميم إدارة المستخدمين من TREZO Smart Treasury

تاريخ المراجعة: 24 أغسطس 2026.

تمت مراجعة الرابط المنشور لمشروع الخزينة الذكية من خلال جلسة مدير النظام. صفحة **المستخدمون والصلاحيات** تعرض عنوانًا واضحًا، بطاقة للمستخدم الحالي والصلاحيات، قسمًا للموظفين والحسابات مع بحث، وسجلًا منفصلًا للموظفين الداخليين.

النمط الوظيفي الظاهر في المشروع المرجعي يميز بين حسابات تسجيل الدخول عبر مزود الهوية وبين الموظفين المحليين بدون بريد إلكتروني. كما يعرض أدوارًا تشغيلية واضحة: محاسب، مراجع، مدير مالي، مدير عام، ومدقق. وتؤكد الصفحة أن صلاحيات الخادم هي مصدر القرار النهائي وأن العمليات الحساسة تُفحص في Backend وليس بمجرد إخفاء عناصر الواجهة.

المطلوب نقله إلى نظام المراجعة هو **النمط والتجربة فقط**: قائمة مستخدمين، بحث، أدوار، حالة الحساب، إضافة موظف محلي، وإدارة صلاحيات ونطاق عمل. لا تُنسخ أسماء أو بيانات أو أرقام أو سجلات من المشروع المرجعي، ولا يتم تنفيذ أي تعديل عليه.
