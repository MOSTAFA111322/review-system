# المراحل المقترحة التالية

## تسويات المالك وشركة الإدارة

تبقى وحدة متابعة الإيجارات الحالية **كشف متابعة غير محاسبي**: تسجل إفادة المستأجر، تأكيد المالك، ورقم سند إملاكي بعد الترحيل. لا ينبغي إضافة عمولة أو قيد تسوية إلى الجداول الحالية قبل اعتماد قواعد العمل الفعلية.

عند اعتماد المرحلة، يكون النموذج المقترح منفصلًا بثلاثة مستويات. يسجل الاستحقاق الإجمالي للسداد، ثم مبلغ المالك المستحق وطريقة حساب أتعاب شركة الإدارة، ثم حالة التسوية وتاريخها ومرجعها. ويجب أن يرتبط كل سجل بحساب المستفيد المختار صراحة: **المالك** أو **شركة الإدارة**، مع منع تسجيل سند محاسبي داخل كشف المتابعة نفسه.

| العنصر | الغرض | قاعدة الحماية |
|---|---|---|
| إجمالي السداد | مطابقة إفادة المستأجر وسند إملاكي | لا يساوي تلقائيًا صافي المالك |
| مبلغ المالك | تحديد ما يخص المالك | لا يتجاوز الإجمالي |
| أتعاب الإدارة | توثيق عمولة الشركة | تتطلب نوعًا ونسبة أو مبلغًا ثابتًا معتمدًا |
| حالة التسوية | غير مسواة، قيد المراجعة، مسواة | لا تصبح مسواة دون مرجع وتاريخ |
| المستفيد | مالك أو شركة إدارة | اختيار إلزامي وسجل تدقيق |

لا توجد بيانات مالك أو نسب عمولة مضافة حاليًا؛ لذلك يلزم اعتماد هذه القواعد من المستخدم قبل تنفيذ الهجرة والإجراءات.

## تطبيق Windows محلي دون إنترنت

النسخة الحالية WebDev تعتمد على OAuth وMySQL/TiDB وخدمات الاستضافة، ولذلك لا تتحول إلى ملف EXE يعمل دون إنترنت بمجرد تغليف الواجهة. المسار الآمن هو إبقاء نسخة الويب هي المصدر الرئيسي، ثم إنشاء تطبيق محلي منفصل عند اعتماد المتطلبات.

| المسار | الملاءمة | الملاحظة |
|---|---|---|
| نسخة ويب داخل المتصفح | متاحة الآن | تحتاج اتصالًا بالخادم وقاعدة البيانات |
| تطبيق سطح مكتب يفتح الويب | سهل | لا يوفر عملًا حقيقيًا دون إنترنت |
| تطبيق محلي كامل | ممكن لاحقًا | يحتاج قاعدة SQLite محلية، مصادقة محلية، مزامنة، وترحيل بيانات |

لذلك لا يُنشأ مجلد أو ملف Windows داخل مشروع الويب الحالي قبل ربط مجلد المستخدم المحلي وتحديد سياسة المزامنة. إنشاء نسخة محلية كاملة يجب أن يكون مشروعًا منفصلًا حتى لا تتأثر نسخة الويب المنشورة.

## قرار التنفيذ

تُحفظ هذه الوثيقة كتصميم تمهيدي. التنفيذ البرمجي للتسويات يتطلب اعتماد قواعد العمولة والحسابات، والتنفيذ المحلي يتطلب ربط مجلد Windows وتحديد ما إذا كان المطلوب نسخة عرض أو نظامًا يعمل دون إنترنت مع مزامنة.
