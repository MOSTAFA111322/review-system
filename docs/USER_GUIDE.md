# دليل الاستخدام والتشغيل — نظام المراجعة المبسط

## البدء الأولي

سجّل الدخول بحساب مدير النظام ثم افتح **لوحة المراجعات**. إذا كانت مساحة العمل جديدة، ستظهر رسالة تهيئة بدلاً من إنشاء أي بيانات تشغيلية تلقائيًا. اختر **تهيئة النظام** مرة واحدة لإعداد الأدوار والصلاحيات والمرجعيات الأساسية اللازمة لتشغيل النظام. بعد ذلك انتقل إلى **الإعدادات** وأنشئ أو راجع السنة المالية الحالية قبل إدخال أول مراجعة فعلية.

| الترتيب | الإجراء | النتيجة |
|---:|---|---|
| 1 | تهيئة النظام بواسطة مدير النظام | إعداد ضوابط النظام والمرجعيات الأولية دون إنشاء مراجعات تجريبية. |
| 2 | الإعدادات ← السنوات المالية | إنشاء السنة وتعيينها كحالية؛ تفصل كل عملياتها عن السنوات الأخرى. |
| 3 | الإعدادات ← سير العمل الديناميكي | مراجعة أنواع العمليات، حالات المراجع وحالات الموظف، وقواعد الانتقال المحكومة بالصلاحية. |
| 4 | المستخدمون والأدوار | ربط المستخدمين بالأدوار والنطاقات السنوية المناسبة. |
| 5 | لوحة المراجعات | إنشاء المراجعات الحقيقية وتكليف الموظف ومتابعة التنفيذ. |

## الأدوار والصلاحيات

تنفذ الصلاحيات في الخادم وواجهة API قبل الوصول إلى البيانات. عناصر الواجهة الموجهة للدور تسهّل الاستخدام فقط، لكن لا تعد وسيلة الحماية الفعلية. يمنح مدير النظام صلاحية شاملة، وتطبق بقية الأدوار وفق الصلاحيات المسندة ونطاق السنة المالية.

| الدور | الاستخدام العملي |
|---|---|
| مدير النظام | تهيئة النظام، إدارة المستخدمين والأدوار والسنوات وسير العمل، واستعراض كامل البيانات والتقارير. |
| مدير | إدارة المراجعات والتكليف والتقارير ضمن الصلاحيات والنطاقات الممنوحة. |
| مراجع | إنشاء المراجعات ومتابعة حالة المراجع والتعليقات ضمن نطاقه. |
| موظف | عرض المراجعات المكلّف بها فقط، وتحديث حالة الموظف وإضافة التعليقات والمرفقات المصرح بها. |

## إنشاء ومتابعة مراجعة

من لوحة المراجعات، اختر إنشاء مراجعة بعد اختيار السنة المالية. أدخل نوع العملية والحالتين الأوليتين والعنوان والوصف والمشكلة والإجراء المطلوب والأولوية والتاريخ المستهدف والموظف المكلّف عند الحاجة. ينشئ النظام رقمًا داخليًا تلقائيًا بصيغة `REV-YYYY-000001` ولا يعتمد على رقم السند كمعرف داخلي.

في صفحة التفاصيل تظهر البيانات الأساسية، والحقول المخصصة المتعلقة بالنوع، والمرفقات، والتعليقات المتسلسلة، وسجل النشاط. تُفرض أي حركة حالة في الخادم وفق انتقال معرّف في الإعدادات والصلاحية المقابلة لها. لا تعتبر المراجعة مكتملة إلا حين تصل حالة المراجع وحالة الموظف إلى حالتين نهائيتين.

> لا تُغلق السنة المالية إلا بعد استكمال مراجعاتها. إغلاق السنة يمنع أي كتابة لاحقة على مراجعاتها في الخادم، بما في ذلك التعديل وتغيير الحالة والتعليق والمرفقات والحذف المنطقي والاستعادة.

## الإعدادات القابلة للتوسعة

تسمح صفحة **الإعدادات** بإدارة الحقول المخصصة وأنواع العمليات وحالات المراجع والموظف وقواعد الانتقال والسنوات المالية. يمكن تعطيل النوع أو الحالة أو الحقل دون حذف السجلات التاريخية المرتبطة به. تدعم الحقول المخصصة النص والرقم والتاريخ والقائمة ونعم/لا، ويمكن ربط الحقل بنوع أو أكثر من أنواع العمليات. تحفظ خيارات القائمة وقيم الحقول في جداول مستقلة كي لا يتغير مخطط المراجعات عند التوسع.

## Dashboard والتقارير

تستخدم شاشة **Dashboard** بيانات المراجعات الفعلية ضمن السنة أو الفترة المحددة لإظهار معدل الإنجاز ومتوسط العمر والمتأخرات وإعادة العمل والتوزيع حسب الأولوية وأداء الموظفين. تحتوي صفحة **التقارير** على فلاتر للفترة والحالة والنوع والموظف، وتصدر نتائج البحث الحالية إلى CSV وExcel. في غياب سنة مالية متاحة، تظهر رسالة موجهة بدلاً من رسم مؤشرات فارغة أو اختراع بيانات.

## المرفقات والتدقيق

يمكن للمستخدم المخول إضافة PDF والصور وExcel وWord إلى المراجعة. يتحقق الخادم من الامتداد والحجم والنوع المسموح، ويحفظ ملف المرفق في التخزين الآمن مع بيانات الرفع واسم الرافِع وتاريخه. يفرض الخادم صلاحية عرض المراجعة قبل إتاحة الوصول إلى المرفق. تسجل العمليات المهمة في سجل النشاط، ويسجل النظام أحداث الدخول والخروج المتاحة لمدير النظام.

## فحوص ما قبل الاستخدام التشغيلي

| فحص | الحالة |
|---|---|
| فحص TypeScript | ناجح (`pnpm check`) |
| اختبارات Vitest | ناجحة: 11 حالة ضمن 4 ملفات اختبار |
| حماية API للمستخدم المجهول | تم التحقق منها |
| RBAC وعزل السنة المغلقة | تم التحقق منهما باختبارات الحراس |
| واجهة الجوال وحالات الفراغ | تم فحصها على عرض 390 بكسل دون إدخال بيانات تجريبية |

لا يضيف النظام مراجعات أو تقييمات أو أرقام أداء مصطنعة بغرض العرض أو الاختبار. يوصى بإجراء اختبار قبول تشغيلي باستخدام بيانات العمل الحقيقية والأدوار الفعلية قبل الاعتماد النهائي في بيئة العمل.
